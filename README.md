## How It Works

This repository uses GitHub Actions to generate an animated Pac-Man version of the GitHub contribution graph and publish the SVG files to the `output` branch.

Important:
This animation will live in this repository. To make it appear directly on the main GitHub profile page, the same README block needs to exist in the special profile repository `Mauricio-HNS/Mauricio-HNS`.
